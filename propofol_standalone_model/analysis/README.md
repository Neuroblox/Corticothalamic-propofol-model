# Analysis scripts

Scripts that simulate the standalone models and plot the simulated multi-unit activity (MUA)
shown in the manuscript.

| Script | Reproduces | Output (in `analysis/output/`) |
|---|---|---|
| `figure3.jl` | Fig 3e–h: posterior and anterior MUA for the LOGO, LOGR and LRGR trials, awake and under propofol | `figure3.png`, `figure3_mua.csv` |
| `figure5.jl` | Fig 5a,c and Fig H in S1 Appendix: posterior MUA and residual inter-stimulus activity across propofol doses | `figure5.png`, `figure5_mua.csv`, `figure5_residual.csv` |

## Running

From the `propofol_standalone_model` folder, install the packages once:

    julia --project=analysis -e 'using Pkg; Pkg.instantiate()'

then run either script:

    julia --project=analysis analysis/figure3.jl
    julia --project=analysis analysis/figure5.jl             # doses 1.0, 1.5, 2.5
    julia --project=analysis analysis/figure5.jl 1 1.25 1.5 1.75 2 2.25 2.5

Each trial takes about as long as with `run.jl` (1–2 min, most of it compiling the model the
first time); `figure3.jl` solves six trials.

## What the scripts compute

- **Simulated MUA** (`simulate` in `common.jl`): the mean synaptic conductance generated by a
  region's neurons. Posterior cortex: the AMPA synapses of the excitatory neurons of layers 2/3,
  4, 5 and 6 of both modules, and the GABA-A synapses of the layer 4 interneurons. Anterior
  cortex: the AMPA synapses of the excitatory neurons of the anterior layer 2/3.
- **Propofol dose** (`parameters_at_dose` in `common.jl`): the awake files correspond to dose
  factor P = 1 and the anesthetized files to P = 2.5. Every dose-dependent parameter is linear in
  P (GABA-A conductance and decay time, and GPi weights, scale as P; the ASC2 weight is 2.5 − P),
  so other doses are obtained by interpolating the two files. The script checks this before
  using it.
- **Residual activity** (`figure5.jl`): the mean posterior MUA in the 50 ms before each of tones
  2–5 of an LRGR trial, averaged over the four windows; net residual activity is its difference
  from the awake value.

## Differences from the manuscript figures

- The model files contain one realization of the circuit's random connectivity, so the traces
  and residual values are those of one realization. The manuscript shows averages (Fig 3) and
  distributions (Fig 5c) over 25 realizations.
- The LRGO trial type is not among the exported trials.
